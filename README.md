This repository contains the web frontend for the _Kommunikationsplattform_ (communication platform, or "KomPla" for short) developed as part of the _Zugang zu Recht_ (Access to Justice / A2J) project in accordance with the _Gesetz zur Entwicklung und Erprobung eines Online-Verfahrens in der Zivilgerichtsbarkeit (OVErpG)_. Its goal is to enable the direct exchange between courts and participating parties in civil court cases. See the [project homepage](https://www.zugang-zum-recht-projekte.de/kommunikationsplattform) for details.

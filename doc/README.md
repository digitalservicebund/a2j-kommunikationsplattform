# KomPla Frontend Documentation

This folder contains the technical documentation for the _Kommunikationsplattform_ (KomPla) frontend. Check the table of contents below or feel free to just browse around.

> [!note]
> To minimize maintenance effort, the technical documentation is only available in English. As an exception, German domain terms like _Verfahren_ (court proceedings) are not translated; however, the first occurrence in a document is accompanied by a rough translation, and all German words are rendered as italic to make them stand out from the surrounding prose.
